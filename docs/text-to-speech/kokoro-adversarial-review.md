# Kokoro source-fidelity and precision review

The publication integration review separates `LoadAuthorConfiguration` from weight loading so an untrained native graph can use the exact released phoneme vocabulary. Public text tokens and the declared input domain now agree with that vocabulary. The generated framework fixture retains the entire 82M topology, supplies a synthetic 256-value style and explicitly opts into the compatibility frontend. This fixture is separate from the released-weight and official-frontend fidelity evidence below; it does not substitute another neural graph.

The native implementation follows the released Kokoro KModel: shared ALBERT, duration/prosody and phoneme encoders, a supplied 256-value acoustic/prosodic voice style, and harmonic iSTFTNet. It does not invent a style predictor or add StyleTTS2's diffusion model. Original checkpoint/configuration and length-indexed voice-bank loading are supported. SynthesizePhonemes exposes the author's language-independent input. Raw text uses a supplied official frontend; the approximate native English frontend now requires explicit UseNativeEnglishFallback opt-in.

The primary references are [hexgrad/kokoro 0.9.4](https://github.com/hexgrad/kokoro/tree/dfb907a02bba8152ca444717ca5d78747ccb4bec) and the original [Kokoro-82M assets](https://huggingface.co/hexgrad/Kokoro-82M/tree/f3ff3571791e39611d31c381e3a41a3af07b4987). The reference runs the unchanged author neural forwards. All 548 stored tensors are accounted for: 546 active native parameters and two explicitly unused ALBERT pooler tensors. The source's 140 later ONNX-export InstanceNorm affine extensions are independently verified identity/zero constants, not invented trained weights.

The adversarial gradient review found two errors that inference alone did not reveal. The shared LSTM wrapper combined PyTorch's two learned biases, changing optimizer updates; TorchLstmCellLayer now retains both. An independent four-step, batch-two PyTorch reference checks all parameters, input/state gradients and an actual AdamW update. Native ALBERT also trained its padding embedding row. Hugging Face suppresses that lookup gradient while retaining the loaded row value and attention to boundary tokens. The correction passes all 23 parameter gradients of a separate shared-ALBERT reference with repeated IDs and a deliberately nonzero loaded padding row.

The complete released neural graph passes all 544 original parameter gradients plus the style-input gradient through the production library: maximum parameter error 3.67e-11, objective error 2.03e-14. The original public inference no-grad decorator is unwrapped only for this derivative audit; the generator's internal detached harmonic branch remains unchanged. Its two merge tensors and the two unused pooler tensors correctly have no gradient in that graph. This secondary neural-gradient comparison explicitly uses promoted double DSP buffers and original detached harmonic-spectrum features; it is not presented as the primary raw waveform comparison or a recovered unpublished training recipe.

The earlier raw waveform mismatch exposed an actual source-buffer error. Kokoro explicitly creates its Hann window and UV/noise-amplitude arithmetic in float32, even when its neural parameters are double. Promoting these buffers changed nearly real spectral bins enough to select the other raw phase branch. The correction retains the original, input-independent 20-point float32 Hann coefficients in BOTH analysis and synthesis and the float32 noise amplitudes. The native paired DFT and raw atan2 remain unchanged: no phase wrapping, near-zero clamping, author-output substitution or tolerance relaxation was used.

Primary production-library comparisons now target the author's ORIGINAL float32 buffers:

- Original nonzero excitation, phonemes hə, speed 20: all 546 active tensors, learned stages and raw harmonic spectrum pass; waveform error 2.67e-9.
- A separately seeded longer sequence, phonemes həloʊ, speed 12: 4,800 samples, waveform error 2.49e-9.
- Independent DSP regressions execute the original SourceModuleHnNSF and TorchSTFT with mixed voiced/unvoiced input, checking source values, merge gradients, the exact float32 window and unmodified raw spectrum. A promoted-window negative control fails the original computation.

A zero-excitation stress case remains explicitly distinguished. Strict intermediate raw phase differences can reach about 5.3e-6 in bins with magnitudes around 1e-9; that angular diagnostic still fails its unchanged 1e-7 threshold. The public production pipeline's complete waveform nevertheless passes its unchanged check with error 2.41e-9. This is not described as exact intermediate phase parity. The failed experiments remain available, including a rejected PocketFFT replacement that did not solve this stress condition and an unchanged-author CPU-thread probe that found no phase flips. The primary stochastic waveform comparisons above pass without adopting that replacement.

Public checkpoint/voice-bank routing, DeepCopy and save/restore into a fresh instance have independently preserved the loaded vocabulary, voice bank and deterministic native waveform under replayed excitation draws. Build88 repeats both the complete 544-gradient check (maximum error 3.67e-11) and fresh-instance save/restore with the new frontend guard and original float32 DSP policy. The expanded 607-case production suite passes; normal-project and framework-specific gates are tracked in the completion audit. External frontend delegates are supplied again after external restoration.

The official Misaki text frontend and unpublished Kokoro corpus/training recipe are not claimed to have been recovered. Callers use the official frontend through TextPhonemizer or provide original phonemes directly. The native English approximation remains available explicitly, with its distinct provenance visible. No model has been removed.
