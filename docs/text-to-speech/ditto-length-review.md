# DiTTo speech-length predictor review

The primary requirements come from [section 3.2 and Appendix A.7 of the paper](https://arxiv.org/html/2406.11427v2#S3.SS2). A causal decoder cross-attends to encoded text and predicts remaining speech length at every prompt position. Training uses cross-entropy. Evaluation uses the expected remaining length under the top-k posterior; the paper uses N=2048 and k=20. Total synthesis length adds the acoustic prompt to that remaining length. Appendix A.7 explicitly supports variable prompt lengths.

`tools/reference-data/ditto_length_reference.py` uses unmodified PyTorch `nn.TransformerDecoder`/`TransformerDecoderLayer` operators for an independent complete numerical reference. The fixture records the Torch version and source hashes for its transformer and functional modules. Two reduced blocks, two attention heads and width eight cover the native pre-norm decoder realization. BOS-only and three-frame-prompt cases compare every output, remaining-length labels, cross-entropy, all 59 learned parameter gradients, text/prompt gradients and the expected-length result. This checks the implemented realization; it does not certify unpublished KRAFTON weights or unspecified private decoder hyperparameters. The native nearest-integer convention for a continuous expectation is retained.

Three additional cross-entropy cases include confident wrong predictions. Native `log(softmax + 1e-12)` capped loss near 27.6 and suppressed the corrective gradient: a logit margin of 37 produced a gradient error of approximately 0.999915, while a margin of 2000 produced error 1. The repair uses differentiable stable log-softmax. Both complete decoder cases already agreed with the independent reference; the loss and gradient stress cases expose four failures and now pass after repair.

Seven inference regressions use independently computed Torch posteriors and the actual native length decoder/synthesis pipeline. A posterior concentrated on class zero was forced to one frame. Synthesis also applied N to prompt plus remaining length, truncating valid predictions and causing slicing failures for longer prompts. It now represents zero remaining length and computes total as prompt plus prediction. Empty total length returns empty audio before invoking the decoder. N bounds the remaining-length class, while prompt frames are added separately; the option's XML documentation states this distinction.

The synthesis cases cover an empty result, a fully supplied prompt, a positive prediction whose total exceeds N, and prompts longer than N with zero or positive continuation. Controlled learned classifier weights make the expected class unique. The existing real Mel-VAE, diffusion and BigVGAN modules execute in the pipeline tests; expected waveform sizes follow the independent total-length result and configured upsampling factors. These are controller/shape regressions, not a trained quality benchmark.

Against the complete prior production baseline Build54, eleven of fifteen new cases fail and four pass. All fifteen pass against the repaired source. The independent complete decoder comparisons use a 1e-9 absolute tolerance. The prior diffusion-field and codec/semantic-training references remain separate evidence.

Build56 compiles the production library on net8.0 and net471 without errors. The normal repository test project passes all 497 reviewed cases on each target, with zero failures or skips; the production-only harness also passes all 497. The checkpoint-audit tool builds without warnings or errors. Two older CosyVoice/Melo fixture helpers now check copied outputs before their repository-root fallback, making the standalone harness portable; copied fixture hashes match the source files.
