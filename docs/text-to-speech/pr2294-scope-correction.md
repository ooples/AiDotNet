# PR #2294 requested-model scope correction

The previous 18-row review register was an incomplete model selection. Rechecking the [actual PR description](https://github.com/ooples/AiDotNet/pull/2294) on 2026-11-03 found four remaining implementations absent from that register: Kokoro, MetaVoice-1B, OpenVoice and OpenVoiceV2. At discovery all four contained hand-written embedding/waveform substitutes. They now have actual native neural implementations. Both OpenVoice versions additionally have independent full training-objective and public optimizer/persistence regressions; MetaVoice has full original-component checkpoints and a complete enhanced public waveform comparison through the production library. Kokoro now passes original-buffer raw waveform comparisons below 2.7e-9, all 544 original neural gradients and clone/fresh-restoration checks. A near-empty-bin angular stress diagnostic remains separately reported; it does not pass as exact intermediate phase parity. The 520 passing Build59 cases do **not** establish completion of the requested 18-model work; current evidence and remaining checks are tracked in the completion audit.

The PR lists 17 remaining named implementations and separately discusses CosyVoiceClone. The requested set is therefore tracked as: Chatterbox, CosyVoice3, CosyVoiceClone, DiTToTTS, E3TTS, Kokoro, MetaVoice1B, OpenVoice, OpenVoiceV2, SeedTTS, SeedTTSClone, SparkTTS, TortoiseTTS, UniAudio, VoiceCraft, Voicebox, XTTSv2 and XTTSv2Clone. Canonical XTTSv2 shares the repaired implementation and now additionally passes the full original-checkpoint audit through an explicit `XTTSv2` instance, rather than being represented only by its cloning facade.

AdaSpeech, AlignTTS, FastSpeech, FastSpeech2 and VALLEXClone were included in the old register in place of those five names. Their repairs and verification remain useful supporting work and must be preserved. They are not substitutes for the omitted requested implementations.

Build59's two successful library builds, 520-case runs on each target, numerical comparisons and production-library hash checks remain valid evidence for the code and tests they actually cover. Its model-presence inventory described the old register, not complete requested-model fidelity. The corrected 18-model review and final Build88 evidence are recorded in the [completion audit](pr2294-completion-audit.md); both normal targets pass all 607 selected regressions. No models or unrelated changes are removed as part of correcting this scope error.
