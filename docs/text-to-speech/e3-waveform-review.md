# E3TTS waveform review

The primary source is [Gao et al., E3 TTS](https://arxiv.org/pdf/2311.00945). Figure 2, on PDF page 4, connects the adaptive kernel bank to both convolutions in an adaptive DBlock/UBlock. The earlier implementation used an expert mixture only for the first convolution and a static second kernel. Both convolutions now use adaptive mixtures. Converted native checkpoints name their banks `first.{expert}` and `second.{expert}`; nonadaptive blocks retain `second`. The authors did not publish their private checkpoint format.

`e3_unet_reference.py` executes an independent PyTorch U-Net and autograd. All ten resolutions, the published stride product 4096, kernel sizes, expert counts, repetition counts, and attention positions are retained. Width is reduced to four, with single-head attention and supplied BERT memory. The 4097-sample input requires internal padding to 8192 and cropping, so a divisible-only canvas cannot pass this reference. Both convolution banks, residual blocks, FiLM, self/cross-attention, speaker conditioning, timestep-only variance, additive skips, and the final waveform projection participate in the objective.

The old production assembly fails the new fixture at its request for the missing static second-convolution tensor. The corrected source harness matches the complete waveform, learned variance, weighted noise objective, all 885 learned tensor gradients, waveform gradient, and text-memory gradient within 1e-8. Every owned parameter is checked. This also exposed unrelated-to-forward gain tensors being registered as trainable in unnormalized convolutions. Registration and generated parameter declarations now include gain only under weight normalization and bias only when enabled.

This reference establishes arithmetic and gradients for the disclosed topology with explicitly documented native choices. It cannot establish private author-weight equivalence. Shared mixture coefficients across the two banks, nearest-neighbor resize, normalization epsilon, pre-normalized attention, and timestep embedding details are native choices where no original implementation is available. The actual BERT dependency and scalar objective have separate checks; supplied text memory is not described as an end-to-end BERT checkpoint comparison.

Build41 passes `net8.0` and `net471`, and all 346 integrated tests pass. The complete 885-tensor comparison now passes against the actual production assembly as well as the source harness. Six parameter-ownership cases cover weight, spectral, and absent normalization with bias enabled/disabled; every optimizer-owned tensor receives a finite gradient. AiDotNet's flat checkpoint count also includes persistent spectral buffers, which are checked separately from optimizer ownership.

The final paper-to-public-path recheck covers section 3.3 timestep/speaker conditioning in both adaptive banks and FiLM, high-index cross-attention to BERT, and the timestep-only variance required by Eq. 6. `TrainingAlphaBar` implements Eq. 4 independently from the inference `AlphaBar` Eq. 7. `Sample` replaces predicted noise with known-region noise for the prompt/edit mask before the DDPM update (sections 5.1.1–5.1.2). Padding is weighted 0.1 and silence detection uses 1024-sample mean-magnitude blocks with threshold 0.02, as disclosed. No original private trained U-Net or corpus convergence claim follows from these checks.
