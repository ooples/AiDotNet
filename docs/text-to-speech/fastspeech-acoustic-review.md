# FastSpeech acoustic integration review

The independent reference executes the complete acoustic graphs in PyTorch, rather than translating native tensor results into expected values. It covers the phoneme embedding, sinusoidal positions, encoder FFT block, duration predictor, length regulator, decoder positions, decoder FFT block, and mel projection. FastSpeech 2 additionally includes the ten-channel CWT predictor, pooled convolution features with the single pitch-statistics projection, quantized pitch and energy embeddings, and energy predictor. Widths and block counts are reduced for the checked fixture; no branch is replaced. Published production defaults are checked separately.

The architecture sources are [FastSpeech sections 3.1–3.3](https://arxiv.org/html/1905.09263v5) and [FastSpeech 2 sections 2.2–2.3 and Appendix C.2](https://arxiv.org/html/2006.04558v8). Later NATSpeech uses a different statistics head; the paper's single projection is retained here. CWT targets execute the vendored original NATSpeech routine with pycwt 0.5.0b0.

`tools/reference-data/fastspeech2_acoustic_reference.py` generates both checked JSON fixtures. `FastSpeech2AcousticReferenceTests` loads their independent weights into the actual production models and compares every acoustic output, every variance prediction, the complete teacher-forced objective, and every owned parameter gradient. All 39 FastSpeech and 63 FastSpeech 2 native parameter tensors are accounted for, including split Q/K/V matrices, normalization parameters, all predictor parameters, and all embedding tables. Maximum permitted error is 1e-9 for outputs and 1e-8 for the objective and gradients. Both variants pass against Build40's .NET 8 production assembly.

This establishes complete reduced-graph arithmetic and gradient agreement. It does not establish author-checkpoint equivalence: the original paper training checkpoints are not supplied by this fixture. FastSpeech consumes externally distilled teacher mel and duration targets; this comparison does not train the autoregressive teacher. FastSpeech 2 consumes forced-alignment durations and recording-derived pitch/energy targets; the waveform extraction routines have separate independent numerical checks. The supplied zero-duration phoneme verifies length regulation without silently inserting a frame for every token.

## AdaSpeech conditioning and joint training

`adaspeech_acoustic_reference.py` extends the independent backbone using [AdaSpeech sections 2.1–2.3](https://arxiv.org/html/2103.00993). It includes both reference acoustic encoders, phoneme-level frame averaging with a zero-duration token, speaker embedding, phoneme predictor, the detached predictor label, conditional decoder normalizations, and final conditional normalization. The projection from the four-dimensional phoneme condition to hidden width remains explicitly a native choice, not a named private author module.

The same production test's third case compares conditioned hidden states, every variance output, mel output, the predictor's auxiliary loss, the complete source-joint objective, and all 96 native learned tensor gradients. All comparisons pass against Build40; source-pretraining/adaptation parameter ownership and updates retain their separate existing tests. A normalization-only match is no longer the sole numerical evidence for AdaSpeech. No Microsoft original checkpoint is inferred from this equation reference.
