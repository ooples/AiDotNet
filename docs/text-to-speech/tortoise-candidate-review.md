# TorToiSe autoregressive candidate handling

The source is [the author's API](https://github.com/neonbjb/tortoise-tts/blob/8a2563ecabe93c4fb626f876dd0c52c966edef2f/tortoise/api.py) and [generation wrapper](https://github.com/neonbjb/tortoise-tts/blob/8a2563ecabe93c4fb626f876dd0c52c966edef2f/tortoise/models/autoregressive.py), pinned to the same revision as the released-checkpoint audit.

The previous native pipeline discarded generated EOS, replaced special tokens with silence, and trimmed candidates before CLVP ranking. Its silence cut retained only one silence token. The author pads generated candidates to the maximum length, runs `fix_autoregressive_output`, ranks the repaired full candidates, recomputes autoregressive latents, and only then cuts those latents at the ninth consecutive silence token. The `[:k]` cut retains eight silence latents so diffusion can terminate speech. Candidate repair replaces the EOS tail with code 83 and ends it with codes 45, 45, 248.

The native synthesis path now preserves generated EOS, pads and repairs candidates before ranking, and slices latents after recomputation. Literal release tail codes are unchanged for the 8,192-entry vocabulary. Explicitly reduced experimental codebooks map these codes modulo their size; lengths below three omit the three-code tail rather than indexing outside the reduced sequence. Those reduced extensions are not claims about the original release.

Generation also omitted the HF prefix from repetition-penalty processing. The original wrapper creates placeholder ID 1 and a speech BOS before generation, and both IDs must participate in penalties. The native sampler now includes them. An optional minimum-token setting now suppresses early EOS in the distribution instead of replacing a sampled EOS with silence; its default is zero, matching the author's unrestricted initial EOS behavior. A hidden `1e-6` temperature floor also changed valid positive-temperature distributions. That floor is removed; the existing public validation requires a positive temperature.

The author initializes the checkpoint with 604 speech positions but the synthesis API defaults to `max_mel_tokens=500`, including when the standard preset supplies its 256 candidates and 200 diffusion steps. The native implementation previously used checkpoint capacity as the generation/padding cap. `MaximumAutoregressiveTokens` now defaults to the original API's 500, independently of `MaxCodecFrames`; smaller experimental checkpoint capacities bound generation as well. The reference extracts the API default from the original function AST. A second full-pipeline regression limits generation to five non-silence tokens and checks the resulting waveform length while retaining the original larger positional table.

`tortoise_candidate_reference.py` executes the original repair function and extracts the actual author silence-cut loop by AST, recording source revision and SHA-256. Eight cases cover early EOS, absent EOS, multiple EOS entries, padded tails, eight versus nine silence tokens, and a reset silence run. Six of eight cases failed against the previous production trim. The new helper passes all eight. Four further cases use actual Hugging Face repetition-penalty, temperature and top-p operators (recorded Transformers version 5.2.0), comparing 28 fixed uniform quantiles of the resulting distributions. The first three failed against the previous production sampler; the fourth independently failed against Build45's retained temperature floor. All four pass against the final repaired source. Fixed quantiles compare distributions; they do not imply identical Torch/native categorical RNG streams.

An additional integration test forces immediate EOS through the real autoregressive head and requires the repaired candidate to produce exactly eight diffusion-conditioning latents, the resulting mel frame count, and the real vocoder's corresponding waveform length. It passes against production Build45. That run passes 53 of 54 Tortoise cases; the sole failure is the newly exposed temperature floor. Final Build47 passes both library frameworks and all 373 integrated tests through the actual repository test project on each of `net8.0` and `net471`, with zero failures or skips. These include the corrected temperature case and the subsequent generation-cap default and full-pipeline tests. The author checkout is clean at its pinned revision, and the recorded API source hash matches it.

Reproduce:

```powershell
python tools/reference-data/tortoise_candidate_reference.py <original-author-checkout>
dotnet test tests/AiDotNet.Tests/AiDotNetTests.csproj -f net8.0 --filter 'FullyQualifiedName~TortoiseCandidateReferenceTests|FullyQualifiedName~ImmediateEos_UsesRepairedCandidate'
```

These checks correct actual public synthesis behavior. They complement the full trained logits, CLVP and 200-step diffusion comparisons; they do not certify corpus training, perceptual quality, or identical free-running stochastic generation across different RNG implementations.
