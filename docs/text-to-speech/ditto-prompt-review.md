# DiTTo cross-sentence text conditioning

[DiTTo v2 section 4, Tasks](https://arxiv.org/html/2406.11427v2) defines cross-sentence synthesis using new text, a reference speech segment, and that segment's different transcript. Section 3.2 trains the backbone on masked speech spans conditioned on the corresponding full text. The native API already stored the transcript in `TtsVoice.ReferenceTokens`, but `Synthesize` discarded it and encoded only the target text. This omitted a supplied paper condition from both the length predictor and diffusion backbone.

Native prompted synthesis now removes the reference transcript's terminal EOS/padding, prefixes those IDs to the target's IDs, retains a single final EOS under the configured text limit, and runs the text encoder once over the joint sequence. Supplying reference tokens without an acoustic prompt leaves the target unchanged. A prompt without transcript continues to accept the caller's complete continuation text. Supplied transcript IDs are validated through the existing `TtsTokenIds` helper; NaN, fractional and out-of-vocabulary values are rejected.

`DiTToPromptConditioningTests` covers short, multiword and truncated joint transcripts. The token boundary is compared with separately tokenizing the complete reference-plus-target sentence, including the real embedded SpeechT5 tokenizer. The tests also execute the complete public synthesis path and compare it with running the verified text encoder on that complete sentence before the existing native latent/codec/vocoder pipeline. Reference tokens must remain unchanged. Two missing-prompt/transcript combinations retain their existing target-only behavior; three invalid-ID cases exercise rejection. The two-block diffusion field uses the independent 63-tensor fixture.

An output-only comparison was insufficient: the tiny RVQ codec can map different latent trajectories to identical waveforms. The final tests therefore assert the conditioning IDs as well as complete waveform wiring. The original production assembly fails all three invalid-ID cases; its ignored transcript is also directly evident in the `Synthesize` source. A source harness exposing that exact former target-only policy through the new internal helper allows the additional conditioning-boundary assertions to run against the old policy; its result is recorded separately from the unmodified production baseline.

`DiTToPublicPromptRoutingTests` adds a ninth, causally sensitive public-path test. It reads the real length decoder's hidden features through an identity classifier and sets that classifier to distinguish joint-text features from target-only features by a large logit margin. The actual networks predict two versus four remaining frames. Real public synthesis must therefore return 20 samples for the joint condition; deliberately bypassing the otherwise-correct helper returns 28 and fails. No encoder, decoder, sampler or codec forward is replaced. This closes the gap left by testing a correct helper and a potentially insensitive tiny waveform alone.

The former-policy adapter fails six cases and passes both target-only invariants. The repaired source passes all eight cases; the ninth routing check also passes against the production assembly and rejects the helper-bypass mutation. Build58 passes both production targets with zero errors, and the actual repository project compiles on both. Net8.0 passes the expanded 512-case suite; net471 passes the 511-case suite plus the subsequently added public-routing case, with unchanged production code. All nine conditioning/routing cases therefore pass on both frameworks, with no failures or skips. SHA-256 checks confirm the test project copied the corresponding current production libraries. A shape assertion in the new sampling tests required an explicit `.ToArray()` for net471; final checks use that portable assertion.

This fixes the missing transcript condition while retaining the existing full prompted-waveform return convention. Exact unreleased author transcript-boundary preprocessing and evaluation-sampler identity remain outside the available evidence; this review does not claim original KRAFTON checkpoint parity.
