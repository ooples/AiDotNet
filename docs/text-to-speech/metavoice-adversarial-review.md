DeepFilterNet's loaded-state flag also survives layer cloning. The public text-token domain uses the checkpoint's 2049 offset, and training accepts the library's canonical `[frames, 8]` codec layout as well as unambiguous legacy codebook-major inputs.

`MetaVoiceNativeFixture` exercises both actual GPTs, the speaker LSTM, native eight-codebook EnCodec and all four native diffusion networks, including both upper-band processors and the complete diffusion schedule. Final validation results are recorded separately in the completion audit.

The public `MetaVoice1B` implementation now connects the actual two transformer stages, checkpoint BPE, speaker encoder, generation policies, EnCodec, four-band diffusion and the released loudness/DeepFilterNet3 output path. The actual 24 kHz EnCodec is verified against the release's pinned Transformers 4.39.2, tokenizers 0.15.2 and Hugging Face Hub 0.21.4, using `facebook/encodec_24khz` revision `c1dbe2ae3f1de713481a3b3e7c47f357092ee040`. A 1 KB full-precision streaming regression reproduces the original failure against build73 and passes against build74. Numerical source audits explicitly retain full checkpoint precision; the framework's automatic quantized inference policy is a separate mode.

DeepFilterNet3's actual 0.5.6 neural graph is now implemented separately in `MetaVoiceDeepFilterNet.cs`, with reduced output/all-gradient fixtures and a full original-checkpoint proof. The pinned source is revision `978576aa8400552a4ce9730838c635aa30db5e61`; its `models/DeepFilterNet3.zip` SHA256 is `49c52edc8947ae1f9bf50d81530beaf3a2c3245aeaf34b6f31ff535cd22284d2`. All 133 stored tensors load strictly, including 86 learned tensors; two output-alpha tensors are author-unused. Full trained outputs match within 1.96e-14 and all active parameter/input gradients within 1.43e-13. The release uses 64 convolution channels, not the class default of 16. Its grouped 1x1 pathways, actual grouped GRUs and complex-filter ordering are retained. A tensor-backend transposed-convolution backward error with output padding was exposed by the gradient fixture; exact zero insertion plus flipped ordinary convolution preserves both source outputs and gradients. Waveform analysis, normalization and synthesis are independently verified by the following actual-runtime and complete public comparisons.

The full 3,840-sample enhancement path also passes against the actual Torch/Torchaudio 2.1.0 CPU runtime, DeepFilterNet 0.5.6 and original libdf DSP: matched-neural-float64/float32-DSP waveform error is 7.68e-7. The [DeepFilterNet paper](https://arxiv.org/html/2305.08227v1#S3) describes ERB-envelope reconstruction and low-frequency complex filtering. The actual released Python preset disables local-SNR gating; native inference preserves that source configuration rather than inventing a gating rule from the paper's optional optimization.

Output policy verification runs unchanged author loudness functions, the actual FFmpeg float32-to-PCM16 writer and the original DF save conversion. It preserves complete 400 ms loudness blocks, clamped K-weighting biquads, strict gates, the low-energy bypass and tanh compression. The first PCM conversion saturates and rounds; DF's final conversion truncates and wraps. Four independent cases and boundary probes distinguish those behaviors.

The complete enhanced public comparison initially failed by 0.00540 at resampling despite exact intermediate PCM. The release requests the legacy `sinc_interpolation` alias; [Torchaudio 2.1.0](https://github.com/pytorch/audio/blob/v2.1.0/torchaudio/functional/functional.py#L1264) warns about its modern name but does not reassign it, so its kernel actually takes the Kaiser branch. Native `MetaVoiceSincFastResample` reproduces that effective filter. Generated float32/float64 DSP coefficients match the isolated pinned 2.1.0 runtime exactly; multitone, impulse and ramp negative controls reject a modern Hann replacement.

The corrected complete public run evaluates the real speaker/actors and full trained decoder, then normalization, intermediate PCM, resampling, trained enhancement and final PCM: 833 uniform draws, 80 Gaussian draws and 20,480 output samples at 48 kHz. Normalization matches within 1.41e-13, resampling within 2.23e-16 and enhanced floating audio within 6.67e-7; final PCM differs by at most one 16-bit step. Float32 DSP precision is explicit, not hidden by increasing the neural comparison tolerance. Both public sample-rate contracts report 48 kHz. The controlled integration fixture uses reduced actor/speaker widths with real vocabularies and full released decoder/enhancer weights; full-size actor checkpoint proofs remain separate.
