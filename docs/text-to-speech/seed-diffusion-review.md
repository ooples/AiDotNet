# Seed-TTS diffusion review

[The Seed-TTS report, section 2](https://arxiv.org/html/2406.02430), discloses an autoregressive speech-token LM followed by a diffusion Transformer and a separately trained vocoder. Section 4.1 retrains diffusion using alternate-timbre tokens, the original timbre reference, and original continuous vocoder embeddings. It does not publish the diffusion schedule, exact denoiser graph, or checkpoint weights.

The earlier native diffusion implementation trained only at a fixed midpoint with the same regenerated noise on every call. Its inference loop averaged clean estimates with `1 / step`, without a matched diffusion schedule. This was insufficient to train a denoiser over its inference noise levels. It also used a generic encoder that applied GELU to the attention output and supplied no frame positional representation.

The correction uses an explicit native variance-preserving linear-beta schedule, a clean-feature objective sampled across training timesteps, and a matching deterministic DDIM sampler. Training noise advances; evaluation recreates a fixed audit RNG without consuming training draws. The dedicated bidirectional Transformer uses linear attention output, exact GELU in its feed-forward network, normalization, residuals and sinusoidal frame/time features. `DiffusionTrainingSteps`, `DiffusionBetaStart`, `DiffusionBetaEnd`, and sampling steps describe these choices. These are standard DDPM/DDIM choices, not claimed ByteDance settings.

`seed_diffusion_reference.py` executes the complete reduced native denoiser independently in PyTorch. Three low/intermediate/high noise cases compare the cumulative schedule, corrupted features, predicted clean features, actual sampled training objective, all 20 native parameter gradients, target/timbre/noise gradients, every DDIM step, and complete sampling output. Only original reference random draws are replayed; no neural forward is replaced. All three source-harness cases pass at 1e-9. The final Build44 .NET 8 production assembly passes all 23 Seed tests within the 356-test integrated suite, including actual tokenizer/diffusion/vocoder and cloning paths, both diffusion/self-distillation training ownership cases, deterministic evaluation, and copied canonical/cloning schedule options. Both library framework builds and the actual repository's net471 test-project compilation pass.

The real DAC-family encoder/quantizer/vocoder and adversarial training remain in the pipeline. This review does not equate those exposed native choices, the UTF-8 text vocabulary, or a numerical equation fixture with ByteDance's undisclosed tokenizer and weights. The cloning class continues to use the same repaired canonical diffusion implementation. Final Build44 passes both library frameworks; the actual repository test project compiles and passes the same 356 reviewed tests on both `net8.0` and `net471`, with zero failures or skips.

The final section-2 routing recheck follows `SynthesizeWithPrompt` through the actual causal speech-token LM, token diffusion and acoustic vocoder. `SeedTTSTokenLanguageModel.Loss` selects only target speech positions, including EOS, after text/prompt context; `Generate` uses causal cached decoding. Section 4.1 training explicitly takes alternate-timbre `PromptCodecTokens`, original-timbre `SpeakerReference` and original recording continuous features. This implements the disclosed autoregressive base and self-distillation method; it does not claim the separately described RL post-training or fully diffusion-based Seed-TTS-DiT variant. Exact proprietary tokenizer/transformer settings remain native documented choices.
