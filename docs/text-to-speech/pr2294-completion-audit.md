# PR #2294 completion audit

## Publication integration review

The publication review also exercises the normal generated model-family tests, separately from the numerical paper references. It found and repaired token-domain declarations in E3TTS, TortoiseTTS, UniAudio, VoiceCraft and SparkTTS; Voicebox's missing public `ITtsModel` declaration; Kokoro's generic training entry point and configured optimizer routing; and MetaVoice's codec vocabulary metadata. MetaVoice now offers an optional synthesis seed, with a native end-to-end regression checking repeated calls and cloning without substituted neural modules. Its default sampling stream remains unchanged.

Generated smoke configurations retain the actual neural components at smaller dimensions. Their prompts, codebook counts and supervision now match each model's contracts. Waveform supervision supplies audio to the model's real frontend instead of labelling waveform samples as a one-channel mel. VoiceCraft smoke utterances are generated by the pinned original eSpeak/phonemizer path. These synthetic fixtures supplement the released-checkpoint comparisons; they do not establish released-weight fidelity themselves.

The [hosted TTS paper-contract run](https://github.com/ooples/AiDotNet/actions/runs/41790009221) also passed all 659 cases in Release on the pushed `886cfc2ac` source. All 665 functional generated checks across the 18 requested model classes now pass. ## Reproduce the selected regression suite

The repository file `tools/TtsCheckpointAudit/review-filter.txt` records the exact 607-case selection, including shared-layer, codec, training, persistence and preserved supporting regressions. From the repository root in PowerShell:

```powershell
$reviewFilter = (Get-Content tools/TtsCheckpointAudit/review-filter.txt -Raw).Trim()
dotnet test tests/AiDotNet.Tests/AiDotNetTests.csproj -f net8.0 --filter $reviewFilter
dotnet test tests/AiDotNet.Tests/AiDotNetTests.csproj -f net471 --filter $reviewFilter
```

These are selected review regressions, not a claim that every repository test has run. Full pretrained-checkpoint comparisons use `tools/TtsCheckpointAudit` with the pinned external source/checkpoint assets and reference generators linked in each model review. The tiny-bin zero-noise Kokoro phase diagnostic retains its failure and unchanged threshold; it must not be reported as passing merely because the complete waveform passes.
