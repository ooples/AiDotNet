## Reproduce the selected regression suite

The repository file `tools/TtsCheckpointAudit/review-filter.txt` records the exact 607-case selection, including shared-layer, codec, training, persistence and preserved supporting regressions. From the repository root in PowerShell:

```powershell
$reviewFilter = (Get-Content tools/TtsCheckpointAudit/review-filter.txt -Raw).Trim()
dotnet test tests/AiDotNet.Tests/AiDotNetTests.csproj -f net8.0 --filter $reviewFilter
dotnet test tests/AiDotNet.Tests/AiDotNetTests.csproj -f net471 --filter $reviewFilter
```

These are selected review regressions, not a claim that every repository test has run. Full pretrained-checkpoint comparisons use `tools/TtsCheckpointAudit` with the pinned external source/checkpoint assets and reference generators linked in each model review. The tiny-bin zero-noise Kokoro phase diagnostic retains its failure and unchanged threshold; it must not be reported as passing merely because the complete waveform passes.
